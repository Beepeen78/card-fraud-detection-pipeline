## To Push to Git

### If repository doesn't exist yet:

```bash
# Initialize repository (if not already done)
git init

# Add all files
git add .

# Create initial commit
git commit -m "Initial commit: Clean fraud detection pipeline

- Complete fraud detection system with Gradio web interface
- Ensemble model training (LightGBM, XGBoost, Random Forest)
- 15 interactive visualizations
- Sample data generator
- Power BI and BigQuery integration
- Comprehensive documentation"

# Add remote repository (replace with your repo URL)
git remote add origin https://github.com/yourusername/card-fraud-detection-pipeline.git

# Push to main branch
git branch -M main
git push -u origin main
```

### If repository already exists:

```bash
# Check current status
git status

# Add all changes
git add .

# Commit changes
git commit -m "Clean project structure and improve organization

- Removed 11 unused/redundant files
- Updated .gitignore to exclude model files and generated data
- Enhanced documentation (README.md, PROJECT_STRUCTURE.md)
- Improved feature engineering with sensible defaults
- Added 15 advanced visualizations
- Cleaned codebase for better maintainability"

# Push to remote
git push origin main
```

## What's Excluded from Git

The following are excluded via .gitignore:
- `*.pkl`, `*.joblib` - Model files (too large, should be generated)
- `sample_transactions.csv` - Generated sample data
- `powerbi/out/*.csv` - Generated Power BI outputs
- `dataset/` - Training data (too large, sensitive)
- `__pycache__/` - Python cache
- `.venv/`, `venv/` - Virtual environments
- IDE files (`.vscode/`, `.idea/`)

## Notes

- Model files should be generated by running `train_improved_model.py`
- Sample data can be regenerated with `generate_sample_dataset.py`
- Training data should be stored separately (not in git)
- The app expects `fraud_lgbm_calibrated.pkl` to exist (generated during training)
